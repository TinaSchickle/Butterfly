# Butterfly – Tagesplan Schilddrüse

Übersichtlicher Tagesplan (Säfte, Tees, Nahrungsergänzung, Rezepte) als installierbare Web-App.

- Statisches `index.html`, kein Build-Schritt nötig
- Installierbar auf Handy/Desktop via Browser-Menü „Zum Startbildschirm hinzufügen“ / „App installieren“
- Läuft dank Service Worker auch offline
